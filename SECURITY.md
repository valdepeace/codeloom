# Seguridad

CodeLoom procesa credenciales de proveedores y puede comunicarse con agentes remotos. No publiques
tokens, claves privadas, datos personales ni pasos de explotación en un issue o pull request.

Envía los informes mediante [Report a vulnerability](https://github.com/valdepeace/codeloom/security/advisories/new).
No abras un issue público con detalles explotables. Si el formulario no está disponible, contacta a
la persona mantenedora mediante el [perfil de GitHub](https://github.com/valdepeace) y pide un canal
privado.

Se priorizará la versión estable más reciente. Antes de la primera release estable, el proyecto se
mantiene como software en desarrollo y no promete soporte para versiones anteriores.
