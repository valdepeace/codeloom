# CodeLoom M3: integración mínima con herdr

Integración opcional mediante el plugin manifest-only de herdr. El pane inicia
`loom`, toma el workspace del contexto de invocación y reporta estado del agente
con el CLI proporcionado por herdr. Standalone sigue usando el directorio actual.

## Tareas

- [x] Añadir `herdr-plugin.toml` con el pane `codeloom.herdr.loom`.
- [x] Añadir `codeloom-herdr`, aislando detección del host y reporte portátil.
- [x] Cambiar el workspace del CLI al `workspace_cwd` inyectado por el host.
- [x] Reportar `idle`, `working` y `blocked`; si falla herdr, seguir standalone.
- [ ] Validar el enlace y abrir el pane en una sesión herdr no elevada.
- [x] Verificar build, test, fmt y clippy del workspace (`target/` local).

## Límites

- La integración usa `HERDR_BIN_PATH`; no implementa transporte de socket propio.
- No registra subagentes M2 como panes independientes.
- Herdr 0.9.3 local rechaza clientes sin privilegios cuando el servidor está
  elevado; la prueba de enlace/runtime queda pendiente hasta disponer de un
  servidor accesible sin cerrar panes existentes.
