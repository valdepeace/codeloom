# batten v0 Implementation Plan (chat core)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un crate general y publicable (`batten`) que da la UI de chat de un agente en el terminal — estado + widgets ratatui — para desarrollar el front de CodeLoom sin el back.

**Architecture:** Dos capas. `state` es puro (sin ratatui/crossterm): transcript, stream, viewport, tool item, composer. `widgets` añade ratatui y un tema con tokens semánticos. `examples/` inyecta eventos falsos. Nada de agente/proveedores/permisos dentro.

**Tech Stack:** Rust stable (edición 2021, heredada del workspace), `ratatui` 0.30, `serde`+`toml`, `unicode-width`. Sin `crossterm` en el crate (los ejemplos lo toman vía `ratatui::crossterm`).

**Spec:** `docs/specs/2026-10-14-batten-design.md`

## Global Constraints

- Crate `batten`, miembro del workspace de loom (`crates/batten`), `version`/`edition`/`license` heredados (`license = "MIT OR Apache-2.0"`).
- `state` NO importa `ratatui` ni `crossterm`. `widgets` NO importa `crossterm`. El crate NO depende de `crossterm`.
- Sin marca CodeLoom dentro del crate; logo y tema neutros.
- Nada de agente, proveedores, permisos o red.
- `cargo fmt --check`, `cargo clippy -- -D warnings` y `cargo test` pasan en cada commit.
- Tests headless (sin terminal real); los widgets se testean con `TestBackend`.

## Review Focus

- **Deltas de streaming partidos a mitad de carácter UTF-8**: `Stream` debe recibir fragmentos y no corromper el texto (nunca cortar un `char` a la mitad). Test en Task 3.
- **Terminal de anchura 0/1 o altura 0**: los widgets no deben entrar en pánico. Test en Task 9/Task 10.
- **Tokens largos sin espacios (URLs/rutas)**: al envolver a un ancho de columna no deben desbordar ni entrar en pánico. Test en Task 9.
- **Anchura de display Unicode (CJK/emoji)**: truncar por anchura de columna, no por bytes. Test en Task 9.
- **Transiciones de estado de tool fuera de orden o duplicadas** (resultado antes de "running", doble resultado): el estado derivado debe quedar consistente. Test en Task 5.

use super::{Line, LineKind, Transcript};

/// Buffer de deltas de una respuesta en curso. Acumula texto y lo "cierra"
/// en una `Line` del transcript cuando se hace `flush`.
#[derive(Debug, Default)]
pub struct Stream {
    buf: String,
}

impl Stream {
    pub fn new() -> Self {
        Self::default()
    }
    pub fn push_text_delta(&mut self, s: &str) {
        self.buf.push_str(s);
    }
    pub fn push_reasoning_delta(&mut self, s: &str) {
        self.buf.push_str(s);
    }
    pub fn pending(&self) -> &str {
        &self.buf
    }
    pub fn is_empty(&self) -> bool {
        self.buf.is_empty()
    }
    pub fn flush(&mut self, out: &mut Transcript) {
        self.flush_as(out, LineKind::Assistant);
    }
    pub fn flush_as(&mut self, out: &mut Transcript, kind: LineKind) {
        if self.buf.is_empty() {
            return;
        }
        let text = std::mem::take(&mut self.buf);
        out.push(Line::new(kind, text));
    }
}

use std::ops::Range;

/// Estado de scroll del transcript. Por defecto sigue el final (lo mas nuevo).
#[derive(Debug, Clone, Copy)]
pub struct Viewport {
    scroll: usize,
    follow_bottom: bool,
}

impl Default for Viewport {
    fn default() -> Self {
        Self { scroll: 0, follow_bottom: true }
    }
}

impl Viewport {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn follow_bottom(&mut self) {
        self.follow_bottom = true;
        self.scroll = 0;
    }

    /// Sube `n` lineas desde abajo (rompe el seguir-el-final).
    pub fn scroll_up(&mut self, n: usize) {
        self.scroll = self.scroll.saturating_add(n);
        self.follow_bottom = false;
    }

    pub fn scroll_down(&mut self, n: usize, total: usize, rows: usize) {
        self.scroll = self.scroll.saturating_sub(n);
        if self.scroll == 0 {
            self.follow_bottom = true;
        }
        if self.follow_bottom {
            return;
        }
        let max = total.saturating_sub(rows);
        let _ = max; // el clamp se aplica en `window`
    }

    /// Rango [start, end) de lineas visibles.
    pub fn window(&self, total: usize, rows: usize) -> Range<usize> {
        if rows == 0 {
            return total..total;
        }
        let rows = rows.min(total.max(1));
        if self.follow_bottom {
            total.saturating_sub(rows)..total
        } else {
            let max_start = total.saturating_sub(rows);
            let start = max_start.saturating_sub(self.scroll.min(max_start));
            start..(start + rows).min(total)
        }
    }
}

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ToolStatus {
    Pending,
    Running,
    Success,
    Error,
    Canceled,
    AwaitingPermission,
}

#[derive(Debug, Clone)]
pub struct ToolItem {
    pub call_id: String,
    pub name: String,
    pub expanded: bool,
    started: bool,
    result: Option<bool>,
    canceled: bool,
    awaiting_permission: bool,
}

impl ToolItem {
    pub fn new(call_id: impl Into<String>, name: impl Into<String>) -> Self {
        Self {
            call_id: call_id.into(),
            name: name.into(),
            expanded: false,
            started: false,
            result: None,
            canceled: false,
            awaiting_permission: false,
        }
    }

    pub fn start(&mut self) {
        self.started = true;
    }
    pub fn await_permission(&mut self) {
        self.awaiting_permission = true;
    }
    pub fn resolve_awaiting(&mut self) {
        self.awaiting_permission = false;
    }
    pub fn set_result(&mut self, is_error: bool) {
        self.result = Some(is_error);
        // Un resultado implica que la tool termino: ya no espera permiso.
        self.awaiting_permission = false;
        self.started = true;
    }
    pub fn cancel(&mut self) {
        self.canceled = true;
    }
    pub fn toggle_expanded(&mut self) {
        self.expanded = !self.expanded;
    }

    /// Estado derivado: el resultado y la cancelacion mandan sobre lo almacenado
    /// para que transiciones fuera de orden o duplicadas queden consistentes.
    pub fn status(&self) -> ToolStatus {
        if self.canceled {
            return ToolStatus::Canceled;
        }
        if let Some(is_error) = self.result {
            return if is_error { ToolStatus::Error } else { ToolStatus::Success };
        }
        if self.awaiting_permission {
            return ToolStatus::AwaitingPermission;
        }
        if self.started {
            ToolStatus::Running
        } else {
            ToolStatus::Pending
        }
    }

    pub fn is_spinning(&self) -> bool {
        self.result.is_none() && !self.canceled && !self.awaiting_permission
    }
}

pub struct Composer {
    buf: String,
}

impl Composer {
    pub fn new() -> Self {
        Self::default()
    }
    pub fn push_char(&mut self, c: char) {
        self.buf.push(c);
    }
    pub fn newline(&mut self) {
        self.buf.push('\n');
    }
    pub fn backspace(&mut self) {
        self.buf.pop();
    }
    pub fn text(&self) -> &str {
        &self.buf
    }
    pub fn is_empty(&self) -> bool {
        self.buf.is_empty()
    }

    /// (y también limpia, para no dejar basura).
    pub fn submit(&mut self) -> Option<String> {
        if self.buf.trim().is_empty() {
            self.buf.clear();
            return None;
        }
        Some(std::mem::take(&mut self.buf))
    }

fn parse_color(s: &str) -> Result<Color, ThemeError> {
    let s = s.trim();
    if let Some(hex) = s.strip_prefix('#') {
        let parse = |i| u8::from_str_radix(&hex[i..i + 2], 16).map_err(|_| ThemeError::Color(s.into()));
        return Ok(Color::Rgb(parse(0)?, parse(2)?, parse(4)?));
    }
    if let Some(idx) = s.strip_prefix("indexed:") {
        return idx
            .parse::<u8>()
            .map(Color::Indexed)
            .map_err(|_| ThemeError::Color(s.into()));
    }
    let c = match s.to_ascii_lowercase().as_str() {
        "black" => Color::Black,
        "red" => Color::Red,
        "green" => Color::Green,
        "yellow" => Color::Yellow,
        "blue" => Color::Blue,
        "magenta" => Color::Magenta,
        "cyan" => Color::Cyan,
        "gray" | "grey" => Color::Gray,
        "white" => Color::White,
        _ => return Err(ThemeError::Color(s.into())),
    };
    Ok(c)
}

use crate::state::StyleToken;
use crate::widgets::Theme;
use ratatui::style::{Color, Style};
use ratatui::text::{Line, Span};
use std::time::Duration;

/// Intervalo entre frames. El bucle de eventos de la app lo usa para tickear.
pub const FRAME_INTERVAL: Duration = Duration::from_millis(50);

const RUNES: &[u8] = b"0123456789abcdef#@$%&*+~";

/// Cualquier item que pueda estar "girando" y avanzar un frame.
pub trait Animatable {
    fn spinning(&self) -> bool;
    /// Avanza un frame; devuelve `true` si sigue girando (o sea, si hay que
    /// re-armar el reloj).
    fn advance(&mut self) -> bool;
}

#[derive(Debug, Clone, Copy, Default)]
pub struct Anim {
    pub frame: u64,
}

impl Anim {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn spinning(&self) -> bool {
        true
    }

    pub fn advance(&mut self) -> bool {
        self.frame = self.frame.wrapping_add(1);
        true
    }

    /// "Scramble" determinista del texto (mismo frame -> mismo resultado) con
    /// degradado del color de acento a lo largo de la linea. Los espacios se
    /// conservan para no mover el layout.
    pub fn render(&self, text: &str, theme: &Theme) -> Line<'static> {
        let from = color_of(theme.style(StyleToken::Accent));
        let to = color_of(theme.style(StyleToken::ToolRunning));
        let n = text.chars().count().max(1);
        let spans: Vec<Span> = text
            .chars()
            .enumerate()
            .map(|(i, c)| {
                let t = if n <= 1 { 0.0 } else { i as f32 / (n - 1) as f32 };
                let color = lerp_color(from, to, t);
                let shown = if c == ' ' {
                    ' '
                } else {
                    RUNES[((self.frame as usize * 7) + i) % RUNES.len()] as char
                };
                Span::styled(shown.to_string(), Style::default().fg(color))
            })
            .collect();
        Line::from(spans)
    }
}

fn color_of(style: Style) -> Color {
    style.fg.unwrap_or(Color::Cyan)
}

fn lerp(a: u8, b: u8, t: f32) -> u8 {
    (a as f32 + (b as f32 - a as f32) * t).round() as u8
}

fn to_rgb(c: Color) -> (u8, u8, u8) {
    match c {
        Color::Rgb(r, g, b) => (r, g, b),
        Color::Cyan => (0, 200, 255),
        Color::Green => (0, 200, 120),
        _ => (200, 200, 200),
    }
}

fn lerp_color(a: Color, b: Color, t: f32) -> Color {
    let (ar, ag, ab) = to_rgb(a);
    let (br, bg, bb) = to_rgb(b);
    Color::Rgb(lerp(ar, br, t), lerp(ag, bg, t), lerp(ab, bb, t))
}

use crate::widgets::Theme;
use ratatui::layout::Rect;
use ratatui::text::{Line as TLine, Span};
use ratatui::widgets::{Paragraph, Wrap};
use ratatui::Frame;

fn prefix(kind: LineKind) -> &'static str {
    match kind {
        LineKind::User => "you: ",
        LineKind::Assistant => "loom: ",
        LineKind::System => "sys: ",
        LineKind::Thinking => "… ",
        LineKind::ToolCall | LineKind::ToolResult => "⚙ ",
        LineKind::Todo => "☐ ",
        LineKind::Plan => "plan: ",
        LineKind::Banner => "",
        LineKind::Error => "! ",
    }
}

fn kind_token(kind: LineKind) -> StyleToken {
    match kind {
        LineKind::User => StyleToken::User,
        LineKind::Assistant => StyleToken::Assistant,
        LineKind::System => StyleToken::System,
        LineKind::Thinking => StyleToken::Muted,
        LineKind::ToolCall | LineKind::ToolResult => StyleToken::ToolName,
        LineKind::Todo => StyleToken::Heading,
        LineKind::Plan => StyleToken::Heading,
        LineKind::Banner => StyleToken::Accent,
        LineKind::Error => StyleToken::Error,
    }
}

/// Convierte una `Line` de estado en lineas ratatui, aplicando los `span` por
/// offsets sobre el texto plano (los huecos usan el token del kind).
fn render_line(line: &Line, theme: &Theme) -> Vec<TLine<'static>> {
    let base = theme.style(kind_token(line.kind));
    let prefix = prefix(line.kind);
    let text = line.plain();
    let mut spans: Vec<Span> = vec![Span::styled(prefix.to_string(), base)];

    if line.spans.is_empty() {
        spans.push(Span::styled(text.to_string(), base));
        return vec![TLine::from(spans)];
    }

    let mut spans_sorted = line.spans.clone();
    spans_sorted.sort_by_key(|s| s.start);
    let mut cursor = 0usize;
    for span in spans_sorted {
        let start = span.start.min(text.len());
        let end = (span.start + span.len).min(text.len());
        if start < cursor {
            continue;
        }
        if cursor < start {
            spans.push(Span::styled(text[cursor..start].to_string(), base));
        }
        spans.push(Span::styled(
            text[start..end].to_string(),
            theme.style(span.token),
        ));
        cursor = end;
    }
    if cursor < text.len() {
        spans.push(Span::styled(text[cursor..].to_string(), base));
    }
    vec![TLine::from(spans)]
}

pub fn render(frame: &mut Frame, area: Rect, transcript: &Transcript, viewport: &Viewport, theme: &Theme) {
    let rows = area.height as usize;
    let range = viewport.window(transcript.len(), rows);
    let mut lines: Vec<TLine> = Vec::new();
    for i in range {
        if let Some(line) = transcript.line(i) {
            lines.extend(render_line(line, theme));
        }
    }
    frame.render_widget(Paragraph::new(lines).wrap(Wrap { trim: false }), area);
}

use crate::state::{StyleToken, ToolItem, ToolStatus};
use crate::widgets::{Anim, Theme};
use ratatui::layout::Rect;
use ratatui::text::{Line, Span};
use ratatui::widgets::{Paragraph, Wrap};
use ratatui::Frame;

fn status_token(status: ToolStatus) -> StyleToken {
    match status {
        ToolStatus::Pending => StyleToken::ToolPending,
        ToolStatus::Running => StyleToken::ToolRunning,
        ToolStatus::Success => StyleToken::ToolSuccess,
        ToolStatus::Error => StyleToken::ToolError,
        ToolStatus::Canceled => StyleToken::ToolCanceled,
        ToolStatus::AwaitingPermission => StyleToken::Warning,
    }
}

pub fn render(frame: &mut Frame, area: Rect, item: &ToolItem, anim: &Anim, theme: &Theme) {
    let status = item.status();
    let glyph = match status {
        ToolStatus::Success => theme.glyphs.tool_success,
        ToolStatus::Error => theme.glyphs.tool_error,
        _ => theme.glyphs.tool_pending,
    };
    let style = theme.style(status_token(status));

    let mut header = vec![
        Span::styled(format!("{glyph} "), style),
        Span::styled(format!("{} ", item.name), theme.style(StyleToken::ToolName)),
    ];
    if item.is_spinning() {
        let spin = anim.render("…", theme);
        header.extend(spin.spans);
    }

    let mut lines = vec![Line::from(header)];
    let body = match status {
        ToolStatus::AwaitingPermission => Some("Requesting permission…"),
        ToolStatus::Running => Some("Waiting for tool response…"),
        ToolStatus::Canceled => Some("Canceled."),
        _ if item.expanded => Some("(expanded output)"),
        _ => None,
    };
    if let Some(text) = body {
        lines.push(Line::from(Span::styled(format!("  {text}"), style)));
    }

    frame.render_widget(Paragraph::new(lines).wrap(Wrap { trim: false }), area);
}

//! Demo sin back: inyecta eventos falsos y muestra los componentes.
//! Uso: `cargo run -p batten --example demo -- basic`
use batten::state::{Composer, Line, LineKind, ToolItem, Transcript, Viewport};
use batten::widgets::{self, Anim, Theme, FRAME_INTERVAL};
use ratatui::crossterm::event::{self, Event, KeyCode};
use std::time::{Duration, Instant};

fn main() -> std::io::Result<()> {
    let scenario = std::env::args().nth(1).unwrap_or_else(|| "basic".into());
    let theme = Theme::default_dark();
    let mut terminal = ratatui::init();

    let mut transcript = Transcript::new();
    let mut composer = Composer::new();
    let viewport = Viewport::new();
    let mut anim = Anim::new();
    let mut tool = ToolItem::new("c1", "view");
    let mut last_tick = Instant::now();
    let started = Instant::now();

    loop {
        // ---- "Eventos" falsos, por tiempo ----
        if scenario == "basic" {
            let secs = started.elapsed().as_secs();
            if transcript.is_empty() {
                transcript.push(Line::new(LineKind::User, "lee hello.txt y dime qué contiene"));
            }
            if secs >= 1 && transcript.len() == 1 {
                transcript.push(Line::new(LineKind::Assistant, "hola mundo"));
            }
        } else {
            if transcript.is_empty() {
                transcript.push(Line::new(LineKind::User, "lee hello.txt"));
                tool.start();
            }
            let secs = started.elapsed().as_secs();
            if secs >= 1 && tool.status() == batten::state::ToolStatus::Running {
                tool.set_result(false);
                transcript.push(Line::new(LineKind::Assistant, "listo"));
            }
        }

        if last_tick.elapsed() >= FRAME_INTERVAL {
            anim.advance();
            last_tick = Instant::now();
        }

        terminal.draw(|f| {
            let area = f.area();
            let rows = ratatui::layout::Layout::vertical([
                ratatui::layout::Constraint::Min(1),
                ratatui::layout::Constraint::Length(3),
            ])
            .split(area);
            if scenario == "tools" {
                let top = ratatui::layout::Layout::vertical([
                    ratatui::layout::Constraint::Length(2),
                    ratatui::layout::Constraint::Min(1),
                ])
                .split(rows[0]);
                widgets::tool_item::render(f, top[0], &tool, &anim, &theme);
                widgets::transcript::render(f, top[1], &transcript, &viewport, &theme);
            } else {
                widgets::transcript::render(f, rows[0], &transcript, &viewport, &theme);
            }
            widgets::composer::render(f, rows[1], &composer, &theme);
        })?;

        if event::poll(Duration::from_millis(16))? {
            if let Event::Key(k) = event::read()? {
                match k.code {
                    KeyCode::Esc | KeyCode::Char('q') => break,
                    KeyCode::Enter => {
                        if let Some(text) = composer.submit() {
                            transcript.push(Line::new(LineKind::User, text));
                        }
                    }
                    KeyCode::Backspace => composer.backspace(),
                    KeyCode::Char(c) => composer.push_char(c),
                    _ => {}
                }
            }
        }
    }

    ratatui::restore();
    Ok(())
}
```
