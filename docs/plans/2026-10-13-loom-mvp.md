# CodeLoom MVP Implementation Plan (m0 + m1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un agente de código en Rust (CLI + TUI ratatui) que habla con un LLM (OpenAI-compatible y Anthropic), ejecuta tools con permisos y completa tareas multi-step.

**Architecture:** Workspace Cargo con `codeloom-core` (motor puro: mensajes, providers, tools, bus de eventos, sesión, step-loop), `codeloom-tui` (ratatui) y `codeloom-cli` (binario). `codeloom-core` no depende de ratatui. Streaming con tokio, tools en paralelo con `JoinSet`, deltas agrupados hacia la UI.

**Tech Stack:** Rust 1.80+, tokio, serde/serde_json, thiserror/anyhow, async-trait, futures, reqwest (rustls), tokio-util (CancellationToken), sqlx (SQLite), ratatui 0.30, crossterm 0.29, ignore/regex/globset, tracing. Test: wiremock, insta, proptest, criterion.

**Spec:** `docs/specs/2026-10-13-loom-design.md`

## Global Constraints

- Rust edition 2021; `rust-toolchain.toml` pineando un stable reciente.
- `codeloom-core` NO puede depender de `ratatui` ni `crossterm` (regla de arquitectura del spec §2).
- No red real en tests: el provider siempre es un mock (`wiremock` o un `Provider` de prueba).
- Toda tool con efectos de escritura es `ExecutionMode::Exclusive`; las de solo lectura, `Parallel`.
- Errores de librería con `thiserror`; el binario puede usar `anyhow`.
- `cargo fmt --check`, `cargo clippy -- -D warnings` y `cargo test` deben pasar en cada commit.
- Todos los paths son relativos a la raíz del workspace `codeloom/`.
- Nomenclatura: producto **CodeLoom**; crate de integración **`codeloom-herdr`** y plugin **`codeloom.herdr`** (solo m3); conjunto de subagentes **"flock"** (solo m2). El MVP no toca herdr ni subagentes.

## Review Focus

Estas clases de entrada/casos probablemente muerdan aunque ningún test de tarea los cubra por nombre; cada línea se fija con un test en la tarea propietaria.

- **SSE partido entre chunks**: un `data:` puede llegar fragmentado en varias lecturas TCP; el parser debe buffear y no perder ni duplicar tokens. (Task 7)
- **`tool_calls` con JSON incremental**: los argumentos llegan como fragmentos; solo el `index`/`id` final identifica la llamada completa. (Task 7)
- **Cancelación a mitad de stream**: cancelar entre deltas no debe dejar un mensaje a medias persistido como respuesta. (Task 13)
- **Edits concurrentes al mismo archivo**: dos `edit` en el mismo step deben serializarse (barrera), no corromper el archivo. (Task 11, 13)
- **Comando con permiso denegado**: debe devolver `ToolResult{is_error}` y, si aplica, `StopTurn`, sin ejecutar nada. (Task 12)

```rust
pub mod codec;

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Role { System, User, Assistant, Tool }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum FinishReason { Stop, Length, ToolCalls, Error }

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Usage { pub input_tokens: u32, pub output_tokens: u32 }

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ContentPart {
    Text { text: String },
    Reasoning { text: String, signature: Option<String> },
    ImageUrl { url: String },
    ToolCall { id: String, name: String, input: serde_json::Value },
    ToolResult { call_id: String, content: String, is_error: bool },
    Finish { reason: FinishReason },
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Message {
    pub id: u64,
    pub role: Role,
    pub parts: Vec<ContentPart>,
    #[serde(default)]
    pub usage: Option<Usage>,
    pub created_at_ms: i64,
}

impl Message {
    pub fn new(role: Role, parts: Vec<ContentPart>) -> Self {
        Self { id: 0, role, parts, usage: None, created_at_ms: now_ms() }
    }
    pub fn user(text: impl Into<String>) -> Self {
        Self::new(Role::User, vec![ContentPart::Text { text: text.into() }])
    }
    pub fn assistant(parts: Vec<ContentPart>) -> Self {
        Self::new(Role::Assistant, parts)
    }
    pub fn text(&self) -> String {
        self.parts
            .iter()
            .filter_map(|p| match p {
                ContentPart::Text { text } => Some(text.as_str()),
                _ => None,
            })
            .collect::<Vec<_>>()
            .join("")
    }
    pub fn tool_calls(&self) -> Vec<(&str, &str, &serde_json::Value)> {
        self.parts
            .iter()
            .filter_map(|p| match p {
                ContentPart::ToolCall { id, name, input } => {
                    Some((id.as_str(), name.as_str(), input))
                }
                _ => None,
            })
            .collect()
    }
}

pub(crate) fn now_ms() -> i64 {
    use std::time::{SystemTime, UNIX_EPOCH};
    SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_millis() as i64
}
```

```rust
use crate::message::Message;
use tokio::sync::broadcast;

#[derive(Debug, Clone)]
pub enum LiveEvent {
    TurnStarted,
    TurnEnded,
    Delta { text: String },
    ReasoningDelta { text: String },
    MessageAdded(Message),
    ToolStarted { call_id: String, name: String },
    ToolFinished { call_id: String, is_error: bool },
    Error { message: String },
}

#[derive(Clone)]
pub struct EventBus {
    tx: broadcast::Sender<LiveEvent>,
}

impl EventBus {
    pub fn new(capacity: usize) -> Self {
        let (tx, _rx) = broadcast::channel(capacity);
        Self { tx }
    }
    pub fn subscribe(&self) -> broadcast::Receiver<LiveEvent> {
        self.tx.subscribe()
    }
    pub fn publish(&self, event: LiveEvent) {
        let _ = self.tx.send(event);
    }
}
```

```rust
use super::{Capabilities, Provider, ProviderRequest, ProviderStream, StreamChunk};
use super::sse::SseBuffer;
use crate::error::{CoreError, Result};
use crate::message::{FinishReason, Usage};
use async_trait::async_trait;
use futures::StreamExt;
use tokio_util::sync::CancellationToken;

#[derive(Default)]
pub struct ToolCallAcc {
    slots: Vec<(String, String, String)>,
}

impl ToolCallAcc {
    pub fn is_empty(&self) -> bool {
        self.slots.is_empty()
    }

    pub fn apply(&mut self, tc: &serde_json::Value) {
        let idx = tc.get("index").and_then(|x| x.as_u64()).unwrap_or(0) as usize;
        while self.slots.len() <= idx {
            self.slots.push((String::new(), String::new(), String::new()));
        }
        let slot = &mut self.slots[idx];
        if let Some(id) = tc.get("id").and_then(|x| x.as_str()) {
            if !id.is_empty() {
                slot.0 = id.to_string();
            }
        }
        if let Some(name) = tc.pointer("/function/name").and_then(|x| x.as_str()) {
            if !name.is_empty() {
                slot.1 = name.to_string();
            }
        }
        if let Some(args) = tc.pointer("/function/arguments").and_then(|x| x.as_str()) {
            slot.2.push_str(args);
        }
    }

    pub fn finish(&mut self) -> Vec<StreamChunk> {
        std::mem::take(&mut self.slots)
            .into_iter()
            .filter(|(id, name, _)| !id.is_empty() || !name.is_empty())
            .map(|(id, name, args)| {
                let input = serde_json::from_str(&args).unwrap_or(serde_json::Value::Null);
                StreamChunk::ToolCallComplete { id, name, input }
            })
            .collect()
    }
}

pub fn map_openai_event(data: &str, acc: &mut ToolCallAcc) -> Vec<StreamChunk> {
    let mut out = Vec::new();
    let v: serde_json::Value = match serde_json::from_str(data) {
        Ok(v) => v,
        Err(_) => return out,
    };
    if let Some(u) = v.get("usage").filter(|u| !u.is_null()) {
        out.push(StreamChunk::Usage(Usage {
            input_tokens: u["prompt_tokens"].as_u64().unwrap_or(0) as u32,
            output_tokens: u["completion_tokens"].as_u64().unwrap_or(0) as u32,
        }));
    }
    let Some(choices) = v.get("choices").and_then(|c| c.as_array()) else {
        return out;
    };
    for c in choices {
        if let Some(delta) = c.get("delta") {
            if let Some(t) = delta.get("content").and_then(|x| x.as_str()) {
                if !t.is_empty() {
                    out.push(StreamChunk::TextDelta(t.to_string()));
                }
            }
            if let Some(r) = delta.get("reasoning_content").and_then(|x| x.as_str()) {
                if !r.is_empty() {
                    out.push(StreamChunk::ReasoningDelta(r.to_string()));
                }
            }
            if let Some(tcs) = delta.get("tool_calls").and_then(|x| x.as_array()) {
                for tc in tcs {
                    acc.apply(tc);
                }
            }
        }
        if let Some(fr) = c.get("finish_reason").and_then(|x| x.as_str()) {
            out.extend(acc.finish());
            let reason = match fr {
                "length" => FinishReason::Length,
                "tool_calls" => FinishReason::ToolCalls,
                _ => FinishReason::Stop,
            };
            out.push(StreamChunk::Done(reason));
        }
    }
    out
}
```

```rust
#[async_trait]
impl Provider for OpenAiCompatProvider {
    fn capabilities(&self) -> Capabilities {
        Capabilities { tool_use: true, reasoning: true, streaming: true }
    }

    async fn stream(&self, req: ProviderRequest, cancel: CancellationToken) -> Result<ProviderStream> {
        let url = format!("{}/chat/completions", self.base_url);
        let resp = self
            .client
            .post(url)
            .bearer_auth(&self.api_key)
            .json(&self.build_body(&req))
            .send()
            .await
            .map_err(|e| CoreError::Provider(e.to_string()))?;
        if !resp.status().is_success() {
            let status = resp.status();
            let text = resp.text().await.unwrap_or_default();
            return Err(CoreError::Provider(format!("http {status}: {text}")));
        }

        struct State<S> {
            stream: S,
            sse: SseBuffer,
            acc: ToolCallAcc,
            queue: std::collections::VecDeque<StreamChunk>,
            cancel: CancellationToken,
            done: bool,
        }

        let init = State {
            stream: resp.bytes_stream(),
            sse: SseBuffer::default(),
            acc: ToolCallAcc::default(),
            queue: std::collections::VecDeque::new(),
            cancel,
            done: false,
        };

        let s = futures::stream::unfold(init, |mut st| async move {
            loop {
                if st.cancel.is_cancelled() {
                    return None;
                }
                if let Some(chunk) = st.queue.pop_front() {
                    if matches!(chunk, StreamChunk::Done(_)) {
                        st.done = true;
                    }
                    return Some((chunk, st));
                }
                if st.done {
                    return None;
                }
                match st.stream.next().await {
                    Some(Ok(bytes)) => {
                        let text = String::from_utf8_lossy(&bytes);
                        for data in st.sse.push(&text) {
                            if data == "[DONE]" {
                                st.queue.extend(st.acc.finish());
                                st.queue.push_back(StreamChunk::Done(FinishReason::Stop));
                            } else {
                                st.queue.extend(map_openai_event(&data, &mut st.acc));
                            }
                        }
                    }
                    _ => {
                        st.queue.extend(st.acc.finish());
                        if !st.queue.iter().any(|c| matches!(c, StreamChunk::Done(_))) {
                            st.queue.push_back(StreamChunk::Done(FinishReason::Stop));
                        }
                    }
                }
            }
        });

        Ok(Box::pin(s))
    }
}
```

```rust
pub struct AnthropicAcc {
    blocks: Vec<(String, String, String)>, // (id, name, json) por index
}

impl AnthropicAcc {
    pub fn is_empty(&self) -> bool {
        self.blocks.is_empty()
    }
    pub fn finish(&mut self) -> Vec<StreamChunk> {
        std::mem::take(&mut self.blocks)
            .into_iter()
            .filter(|(_, name, _)| !name.is_empty())
            .map(|(id, name, json)| StreamChunk::ToolCallComplete {
                id,
                name,
                input: serde_json::from_str(&json).unwrap_or(serde_json::Value::Null),
            })
            .collect()
    }
}

pub fn map_anthropic_event(event: &str, data: &str, acc: &mut AnthropicAcc) -> Vec<StreamChunk> {
    let mut out = Vec::new();
    let v: serde_json::Value = match serde_json::from_str(data) {
        Ok(v) => v,
        Err(_) => return out,
    };
    match event {
        "content_block_start" => {
            let idx = v["index"].as_u64().unwrap_or(0) as usize;
            while acc.blocks.len() <= idx {
                acc.blocks.push((String::new(), String::new(), String::new()));
            }
            let cb = &v["content_block"];
            if cb["type"] == "tool_use" {
                acc.blocks[idx].0 = cb["id"].as_str().unwrap_or_default().to_string();
                acc.blocks[idx].1 = cb["name"].as_str().unwrap_or_default().to_string();
            }
        }
        "content_block_delta" => {
            let idx = v["index"].as_u64().unwrap_or(0) as usize;
            let d = &v["delta"];
            match d["type"].as_str().unwrap_or("") {
                "text_delta" => out.push(StreamChunk::TextDelta(
                    d["text"].as_str().unwrap_or_default().to_string(),
                )),
                "thinking_delta" => out.push(StreamChunk::ReasoningDelta(
                    d["thinking"].as_str().unwrap_or_default().to_string(),
                )),
                "input_json_delta" => {
                    while acc.blocks.len() <= idx {
                        acc.blocks.push((String::new(), String::new(), String::new()));
                    }
                    acc.blocks[idx]
                        .2
                        .push_str(d["partial_json"].as_str().unwrap_or_default());
                }
                _ => {}
            }
        }
        "message_start" => {
            if let Some(u) = v.pointer("/message/usage") {
                out.push(StreamChunk::Usage(Usage {
                    input_tokens: u["input_tokens"].as_u64().unwrap_or(0) as u32,
                    output_tokens: u["output_tokens"].as_u64().unwrap_or(0) as u32,
                }));
            }
        }
        "message_delta" => {
            if let Some(u) = v.get("usage").filter(|u| !u.is_null()) {
                out.push(StreamChunk::Usage(Usage {
                    input_tokens: 0,
                    output_tokens: u["output_tokens"].as_u64().unwrap_or(0) as u32,
                }));
            }
            out.extend(acc.finish());
            let reason = match v.pointer("/delta/stop_reason").and_then(|x| x.as_str()).unwrap_or("") {
                "tool_use" => FinishReason::ToolCalls,
                "max_tokens" => FinishReason::Length,
                _ => FinishReason::Stop,
            };
            out.push(StreamChunk::Done(reason));
        }
        _ => {}
    }
    out
}
```

```rust
impl Provider for AnthropicProvider {
    fn capabilities(&self) -> Capabilities {
        Capabilities { tool_use: true, reasoning: true, streaming: true }
    }

    async fn stream(&self, req: ProviderRequest, cancel: CancellationToken) -> Result<ProviderStream> {
        let url = format!("{}/v1/messages", self.base_url);
        let resp = self
            .client
            .post(url)
            .header("x-api-key", &self.api_key)
            .header("anthropic-version", "2023-06-01")
            .json(&self.build_body(&req))
            .send()
            .await
            .map_err(|e| CoreError::Provider(e.to_string()))?;
        if !resp.status().is_success() {
            let status = resp.status();
            let text = resp.text().await.unwrap_or_default();
            return Err(CoreError::Provider(format!("http {status}: {text}")));
        }

        struct State<S> {
            stream: S,
            sse: SseBuffer,
            acc: AnthropicAcc,
            queue: std::collections::VecDeque<StreamChunk>,
            cancel: CancellationToken,
            done: bool,
        }

        let init = State {
            stream: resp.bytes_stream(),
            sse: SseBuffer::default(),
            acc: AnthropicAcc::default(),
            queue: std::collections::VecDeque::new(),
            cancel,
            done: false,
        };

        let s = futures::stream::unfold(init, |mut st| async move {
            loop {
                if st.cancel.is_cancelled() {
                    return None;
                }
                if let Some(chunk) = st.queue.pop_front() {
                    if matches!(chunk, StreamChunk::Done(_)) {
                        st.done = true;
                    }
                    return Some((chunk, st));
                }
                if st.done {
                    return None;
                }
                match st.stream.next().await {
                    Some(Ok(bytes)) => {
                        let text = String::from_utf8_lossy(&bytes);
                        for (name, data) in st.sse.push_events(&text) {
                            st.queue.extend(map_anthropic_event(&name, &data, &mut st.acc));
                        }
                    }
                    _ => {
                        st.queue.extend(st.acc.finish());
                        if !st.queue.iter().any(|c| matches!(c, StreamChunk::Done(_))) {
                            st.queue.push_back(StreamChunk::Done(FinishReason::Stop));
                        }
                    }
                }
            }
        });

        Ok(Box::pin(s))
    }
}
```

```rust
impl Tool for GrepTool {
    fn name(&self) -> &str { "grep" }
    fn description(&self) -> &str {
        "Search file contents by regex. Params: pattern (string), glob (optional string)."
    }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "type":"object",
            "properties":{"pattern":{"type":"string"},"glob":{"type":"string"}},
            "required":["pattern"]

    async fn run(&self, ctx: ToolCtx, input: serde_json::Value, _c: CancellationToken) -> Result<ToolOutput> {

        let re = regex::Regex::new(pattern).map_err(|e| CoreError::Tool(e.to_string()))?;
        let cwd = ctx.cwd.clone();
        let hits = tokio::task::spawn_blocking(move || {
            let mut out = Vec::new();
            for entry in ignore::WalkBuilder::new(&cwd).build().flatten() {
                if !entry.file_type().map(|t| t.is_file()).unwrap_or(false) {
                    continue;
                }
                let Ok(content) = std::fs::read_to_string(entry.path()) else { continue };
                for (i, line) in content.lines().enumerate() {
                    if re.is_match(line) {
                        out.push(format!("{}:{}: {}", entry.path().display(), i + 1, line));
                    }
                }
            }
            out
        })
        .await
        .map_err(|e| CoreError::Tool(e.to_string()))?;
        Ok(ToolOutput::ok(hits.join("\n")))
    }
```

```rust
use super::{ExecutionMode, Tool, ToolCtx, ToolOutput};
use crate::error::{CoreError, Result};
use async_trait::async_trait;
use tokio_util::sync::CancellationToken;

const BANNED: [&str; 3] = ["rm -rf /", "mkfs", ":(){"];

pub struct BashTool;

#[async_trait]
impl Tool for BashTool {
    fn name(&self) -> &str { "bash" }
    fn description(&self) -> &str { "Run a shell command in the workspace. Params: command (string)." }
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({"type":"object","properties":{"command":{"type":"string"}},"required":["command"]})
    }
    fn execution_mode(&self, _i: &serde_json::Value) -> ExecutionMode { ExecutionMode::Exclusive }
    async fn run(&self, ctx: ToolCtx, input: serde_json::Value, cancel: CancellationToken) -> Result<ToolOutput> {
        let command = input["command"].as_str().unwrap_or_default();
        if BANNED.iter().any(|b| command.contains(b)) {
            return Ok(ToolOutput::err("command blocked by policy"));
        }
        let (prog, flag) = if cfg!(windows) { ("cmd", "/C") } else { ("sh", "-c") };
        let mut child = tokio::process::Command::new(prog)
            .arg(flag)
            .arg(command)
            .current_dir(&ctx.cwd)
            .stdout(std::process::Stdio::piped())
            .stderr(std::process::Stdio::piped())
            .spawn()
            .map_err(|e| CoreError::Tool(e.to_string()))?;
        tokio::select! {
            out = child.wait_with_output() => {
                let out = out.map_err(|e| CoreError::Tool(e.to_string()))?;
                let mut text = String::from_utf8_lossy(&out.stdout).to_string();
                text.push_str(&String::from_utf8_lossy(&out.stderr));
                if out.status.success() { Ok(ToolOutput::ok(text)) } else { Ok(ToolOutput::err(text)) }
            }
            _ = cancel.cancelled() => {
                let _ = child.kill().await;
                Ok(ToolOutput::err("cancelled"))
            }
        }
    }
}
```

```rust
use async_trait::async_trait;
use std::collections::HashSet;
use tokio::sync::Mutex;

#[derive(Debug, Clone)]
pub struct PermissionRequest {
    pub tool: String,
    pub action: String,
    pub detail: String,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Decision { Allow, Deny }

#[async_trait]
pub trait PermissionResponder: Send + Sync {
    async fn decide(&self, req: &PermissionRequest) -> Decision;
}

pub struct AllowAll;

#[async_trait]
impl PermissionResponder for AllowAll {
    async fn decide(&self, _req: &PermissionRequest) -> Decision { Decision::Allow }
}

pub struct DenyAll;

#[async_trait]
impl PermissionResponder for DenyAll {
    async fn decide(&self, _req: &PermissionRequest) -> Decision { Decision::Deny }
}

pub struct PermissionService {
    responder: Box<dyn PermissionResponder>,
    persistent: Mutex<HashSet<String>>,
}

impl PermissionService {
    pub fn allow_all() -> Self {
        Self { responder: Box::new(AllowAll), persistent: Mutex::new(HashSet::new()) }
    }
    pub fn with_responder(responder: Box<dyn PermissionResponder>) -> Self {
        Self { responder, persistent: Mutex::new(HashSet::new()) }
    }
    pub fn key(tool: &str, action: &str) -> String {
        format!("{tool}:{action}")
    }
    pub async fn check(&self, req: PermissionRequest) -> Decision {
        if self.persistent.lock().await.contains(&Self::key(&req.tool, &req.action)) {
            return Decision::Allow;
        }
        self.responder.decide(&req).await
    }
    pub async fn grant_persistent(&self, tool: &str, action: &str) {
        self.persistent.lock().await.insert(Self::key(tool, action));
    }
}
```

```rust
use crate::tools::{ExecutionMode, ToolCtx, ToolOutput, ToolRegistry};
use futures::StreamExt;

/// Ejecuta tool calls respetando barreras:
/// las `Exclusive` se ejecutan solas y en orden; las `Parallel` en un lote comun.
pub async fn execute_tools(
    registry: &ToolRegistry,
    ctx: ToolCtx,
    calls: Vec<(String, String, serde_json::Value)>,
    cancel: tokio_util::sync::CancellationToken,
) -> Vec<(String, ToolOutput)> {
    let mut batches: Vec<Vec<(String, String, serde_json::Value)>> = Vec::new();
    let mut current: Vec<(String, String, serde_json::Value)> = Vec::new();
    for (id, name, input) in calls {
        let mode = registry
            .get(&name)
            .map(|t| t.execution_mode(&input))
            .unwrap_or(ExecutionMode::Exclusive);
        match mode {
            ExecutionMode::Parallel => current.push((id, name, input)),
            ExecutionMode::Exclusive => {
                if !current.is_empty() {
                    batches.push(std::mem::take(&mut current));
                }
                batches.push(vec![(id, name, input)]);
            }
        }
    }
    if !current.is_empty() {
        batches.push(current);
    }

    let mut results = Vec::new();
    for batch in batches {
        let futs = batch.into_iter().map(|(id, name, input)| {
            let tool = registry.get(&name);
            let ctx = ctx.clone();
            let cancel = cancel.clone();
            async move {
                match tool {
                    Some(t) => {
                        let out = t
                            .run(ctx, input, cancel)
                            .await
                            .unwrap_or_else(|e| ToolOutput::err(e.to_string()));
                        (id, out)
                    }
                    None => (id, ToolOutput::err(format!("unknown tool: {name}"))),
                }
            }
        });
        let collected: Vec<_> = futures::stream::iter(futs).buffer_unordered(8).collect().await;
        results.extend(collected);
    }
    results
}
```

```rust
impl AgentLoop {
    pub async fn run(
        &self,
        session: SessionId,
        user_prompt: String,
        cancel: CancellationToken,
    ) -> Result<TurnOutcome> {
        self.bus.publish(LiveEvent::TurnStarted);
        let mut history = self.store.messages(session).await?;
        let user = Message::user(user_prompt);
        self.store.append_message(session, &user).await?;
        self.bus.publish(LiveEvent::MessageAdded(user.clone()));
        history.push(user);

        let ctx = ToolCtx { cwd: self.cwd.clone(), permission: self.permission.clone() };
        let mut steps = 0usize;
        let mut final_text = String::new();

        loop {
            steps += 1;
            if steps > self.config.max_steps {
                break;
            }
            let req = ProviderRequest {
                model: self.config.model.clone(),
                system: String::new(),
                messages: history.clone(),
                tools: self.tools.specs(),
                temperature: 0.0,
                max_tokens: 4096,
            };
            let mut stream = self.provider.stream(req, cancel.clone()).await?;
            let mut text_buf = String::new();
            let mut tool_calls: Vec<(String, String, serde_json::Value)> = Vec::new();
            let mut finish = FinishReason::Stop;
            while let Some(chunk) = stream.next().await {
                match chunk {
                    StreamChunk::TextDelta(t) => {
                        text_buf.push_str(&t);
                        self.bus.publish(LiveEvent::Delta { text: t });
                    }
                    StreamChunk::ReasoningDelta(r) => {
                        self.bus.publish(LiveEvent::ReasoningDelta { text: r });
                    }
                    StreamChunk::ToolCallComplete { id, name, input } => {
                        tool_calls.push((id, name, input));
                    }
                    StreamChunk::Done(r) => finish = r,
                    _ => {}
                }
            }

            let mut parts = Vec::new();
            if !text_buf.is_empty() {
                parts.push(ContentPart::Text { text: text_buf.clone() });
            }
            for (id, name, input) in &tool_calls {
                parts.push(ContentPart::ToolCall {
                    id: id.clone(),
                    name: name.clone(),
                    input: input.clone(),
                });
            }
            parts.push(ContentPart::Finish { reason: finish });
            let assistant = Message::assistant(parts);
            self.store.append_message(session, &assistant).await?;
            self.bus.publish(LiveEvent::MessageAdded(assistant.clone()));
            history.push(assistant);
            final_text = text_buf;

            if tool_calls.is_empty() {
                break;
            }

            let results =
                dispatch::execute_tools(&self.tools, ctx.clone(), tool_calls, cancel.clone()).await;
            for (id, out) in results {
                let tr = Message::new(
                    Role::Tool,
                    vec![ContentPart::ToolResult {
                        call_id: id,
                        content: out.content,
                        is_error: out.is_error,
                    }],
                );
                self.store.append_message(session, &tr).await?;
                self.bus.publish(LiveEvent::MessageAdded(tr.clone()));
                history.push(tr);
            }
        }

        self.bus.publish(LiveEvent::TurnEnded);
        Ok(TurnOutcome { session, final_text, steps })
    }
}
```

```rust
#[derive(Default, Clone)]
pub struct TranscriptItem {
    pub role: &'static str,
    pub text: String,
}

pub struct App {
    pub items: Vec<TranscriptItem>,
    pub input: String,
    pub status: String,
    pub should_quit: bool,
}

impl App {
    pub fn new() -> Self {
        Self { items: Vec::new(), input: String::new(), status: "ready".into(), should_quit: false }
    }

    pub fn apply(&mut self, ev: LiveEvent) {
        match ev {
            LiveEvent::TurnStarted => self.status = "working".into(),
            LiveEvent::TurnEnded => self.status = "ready".into(),
            LiveEvent::Delta { text } => {
                if let Some(last) = self.items.last_mut() {
                    if last.role == "assistant" {
                        last.text.push_str(&text);
                        return;
                    }
                }
                self.items.push(TranscriptItem { role: "assistant", text });
            }
            LiveEvent::MessageAdded(m) => {
                if m.role == codeloom_core::message::Role::User {
                    self.items.push(TranscriptItem { role: "you", text: m.text() });
                }
            }
            LiveEvent::Error { message } => self.status = format!("error: {message}"),
            _ => {}
        }
    }

    pub fn push_char(&mut self, c: char) {
        self.input.push(c);
    }
    pub fn backspace(&mut self) {
        self.input.pop();
    }
    pub fn submit(&mut self) -> Option<String> {
        if self.input.trim().is_empty() {
            return None;
        }
        let text = std::mem::take(&mut self.input);
        self.items.push(TranscriptItem { role: "you", text: text.clone() });
        Some(text)
    }
}
```

```rust
pub struct UiPermissionResponder {
    tx: mpsc::Sender<(PermissionRequest, oneshot::Sender<Decision>)>,
    auto_allow: bool,
}

impl UiPermissionResponder {
    pub fn new(tx: mpsc::Sender<(PermissionRequest, oneshot::Sender<Decision>)>, auto_allow: bool) -> Self {
        Self { tx, auto_allow }
    }
}

#[async_trait]
impl PermissionResponder for UiPermissionResponder {
    async fn decide(&self, req: &PermissionRequest) -> Decision {
        if self.auto_allow {
            return Decision::Allow;
        }
        let (reply_tx, reply_rx) = oneshot::channel();
        if self.tx.send((req.clone(), reply_tx)).await.is_err() {
            return Decision::Deny;
        }
        reply_rx.await.unwrap_or(Decision::Deny)
    }
}
```

```rust
use crate::app::App;
use crate::render::render;
use crossterm::event::{self, Event, KeyCode, KeyEventKind};
use crossterm::terminal::{disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen};
use crossterm::{execute, ExecutableCommand};
use ratatui::backend::CrosstermBackend;
use ratatui::Terminal;
use std::io::Stdout;
use std::time::Duration;

pub fn setup() -> std::io::Result<Stdout> {
    enable_raw_mode()?;
    let mut out = std::io::stdout();
    execute!(out, EnterAlternateScreen)?;
    Ok(out)
}

pub fn teardown(mut out: Stdout) -> std::io::Result<()> {
    disable_raw_mode()?;
    out.execute(LeaveAlternateScreen)?;
    Ok(())
}

/// Bucle principal: aplica eventos del bus y lee teclado.
pub async fn run(
    mut app: App,
    prompt_tx: tokio::sync::mpsc::Sender<String>,
    mut bus_rx: tokio::sync::broadcast::Receiver<codeloom_core::event::LiveEvent>,
) -> std::io::Result<()> {
    let out = setup()?;
    let backend = CrosstermBackend::new(out);
    let mut terminal = Terminal::new(backend)?;
    while !app.should_quit {
        while let Ok(ev) = bus_rx.try_recv() {
            app.apply(ev);
        }
        terminal.draw(|f| render(f, &app))?;
        if event::poll(Duration::from_millis(50))? {
            if let Event::Key(key) = event::read()? {
                if key.kind == KeyEventKind::Press {
                    match key.code {
                        KeyCode::Char('q') if key.modifiers.contains(crossterm::event::KeyModifiers::CONTROL) => {
                            app.should_quit = true;
                        }
                        KeyCode::Enter => {
                            if let Some(text) = app.submit() {
                                let _ = prompt_tx.try_send(text);
                            }
                        }
                        KeyCode::Backspace => app.backspace(),
                        KeyCode::Char(c) => app.push_char(c),
                        _ => {}
                    }
                }
            }
        }
    }
    let _ = teardown(std::io::stdout());
    Ok(())
}
```

```rust
fn signature(m: &Message) -> Option<Vec<String>> {
    let calls: Vec<String> = m
        .parts
        .iter()
        .filter_map(|p| match p {
            ContentPart::ToolCall { name, input, .. } => Some(format!("{name}:{input}")),
            _ => None,
        })
        .collect();
    if calls.is_empty() { None } else { Some(calls) }
}

/// Para si se supero `max_steps` o si los ultimos dos mensajes del asistente
/// repiten las mismas tool calls (bucle).
pub fn should_stop(history: &[Message], steps: usize, max_steps: usize) -> bool {
    if steps >= max_steps {
        return true;
    }
    let sigs: Vec<Vec<String>> = history
        .iter()
        .filter(|m| m.role == Role::Assistant)
        .filter_map(signature)
        .collect();
    if sigs.len() >= 2 && sigs[sigs.len() - 1] == sigs[sigs.len() - 2] {
        return true;
    }
    false
}
```

```rust
pub async fn stream_with_retry(
    provider: &dyn Provider,
    req: ProviderRequest,
    cancel: CancellationToken,
    max_retries: u32,
) -> Result<ProviderStream> {
    let mut attempt = 0u32;
    loop {
        match provider.stream(req.clone(), cancel.clone()).await {
            Ok(s) => return Ok(s),
            Err(e) if attempt < max_retries => {
                let backoff = std::time::Duration::from_millis(250 * 2u64.pow(attempt));
                tracing::warn!("provider retry {attempt}: {e}");
                tokio::select! {
                    _ = tokio::time::sleep(backoff) => {}
                    _ = cancel.cancelled() => return Err(crate::error::CoreError::Cancelled),
                }
                attempt += 1;
            }
            Err(e) => return Err(e),
        }
    }
}
```
